# 스레드 자동발행 대시보드

스레드(Threads) 공식 API로 글을 예약 발행하고, 발행된 글의 조회수를 자동 수집해서
오늘 발송 예정/완료 건수, 시간대별 발행 현황, 조회수 합계를 보여주는 대시보드입니다.
쿠팡파트너스 Open API와도 연동되어 있어 키워드 검색만으로 상품 사진·가격·파트너스 링크를
자동으로 가져와 글을 채울 수 있습니다.

## 1. 로컬에서 먼저 확인해보기

```
npm install
npm start
```

브라우저에서 http://localhost:3000 접속. (아직 계정 연결은 안 된 상태 — 화면 구조만 먼저 확인 가능)

## 2. 쿠팡파트너스 Open API 키 발급 (건우님이 직접 하셔야 하는 부분)

쿠팡파트너스는 이미 가입되어 있다는 전제로:

1. https://partners.coupang.com 로그인 → 상단 메뉴 또는 계정 설정에서 **"Open API"** / "개발자 센터" 메뉴 찾기
2. Access Key / Secret Key 발급받기 (즉시 발급되는 경우가 많음, 별도 심사 없을 수 있음)
3. 대시보드 **연결 설정** 탭 → "쿠팡파트너스 API 연결"에 Access Key/Secret Key 입력 → 저장

이렇게 하면 **글 예약** 탭에서 키워드로 상품을 검색하면 파트너스 링크·상품 사진·가격이
한번에 채워집니다. (링크를 직접 붙여넣는 기존 방식도 계속 사용 가능하며, 이 경우엔 og:image
스크래핑으로 사진만 보조로 가져옵니다.)

⚠️ 검색 API는 호출 빈도 제한이 있습니다(체감상 시간당 10회 수준이라는 사용기가 있음, 정책은
계속 바뀔 수 있음). 검색을 너무 자주 반복하지 마시고, 한 번 검색한 결과에서 필요한 상품을
바로 선택해서 쓰는 걸 권장합니다.

## 3. 스레드(Threads) Meta 개발자 앱 만들기 (건우님이 직접 하셔야 하는 부분)

1. https://developers.facebook.com 접속 → 로그인 (본인 스레드 계정과 연결된 Instagram/Facebook 계정 필요)
2. "내 앱" → "앱 만들기" → 유형은 "기타" 또는 "비즈니스" 선택
3. 앱 대시보드에서 "제품 추가" → **Threads API** 추가
4. Threads API 설정 화면에서:
   - **Threads App ID**, **Threads App Secret** 확인 (연결 설정 탭에 입력할 값)
   - **유효한 OAuth 리디렉션 URI**에 배포 주소 + `/auth/callback` 등록
     - 예: `https://내앱주소.up.railway.app/auth/callback`
     - 로컬 테스트 시엔 `http://localhost:3000/auth/callback`
5. 앱이 "개발 모드"일 때는 본인 계정(테스트 사용자로 등록된 계정)만 로그인 가능합니다.
   본인 계정만 쓸 거면 개발 모드로도 충분합니다 (별도 심사 불필요).

## 4. 앱에 연결 정보 입력

배포 후 대시보드의 **연결 설정** 탭에서 App ID / App Secret / Redirect URI 입력 → 저장 →
"스레드 계정으로 연결하기" 클릭 → 스레드 로그인 화면에서 권한 동의 → 자동으로 대시보드로 복귀.

연결되면 상단에 "연결됨 · @계정명"이 표시됩니다.

## 5. 배포 (24시간 자동 발행이 되려면 서버가 계속 켜져 있어야 함)

로컬 PC를 계속 켜둘 게 아니라면 아래 중 하나에 올리는 걸 추천합니다.

- **Railway** (railway.app) — Node 프로젝트 그대로 올리면 자동 인식, 무료 크레딧 있음
- **Render** (render.com) — Web Service로 배포, 무료 플랜은 슬립 모드 있으니 유료 권장
- 이전에 쓰시던 **Replit**도 가능 (Always On 옵션 필요)

배포 시 환경변수(`.env.example` 참고)로 App ID/Secret/Redirect URI를 넣어도 되고,
첫 배포 후 웹 화면의 "연결 설정" 탭에서 직접 입력해도 됩니다.

⚠️ SQLite 파일(`db/scheduler.db`)에 예약 글과 토큰이 저장됩니다. 무료 플랜 중에는
재배포할 때마다 파일시스템이 초기화되는 곳도 있으니(Render 무료 플랜 등), 배포 전에
호스팅의 "영구 디스크/볼륨" 옵션을 확인하세요. Railway는 기본 지원합니다.

## 6. 사용 흐름

1. **글 예약** 탭 상단의 **쿠팡파트너스 상품 검색**에서 키워드 검색 → 원하는 상품 "선택"
   → 파트너스 링크·상품 사진·상품명이 자동으로 채워짐 (가장 추천하는 방법)
   - 또는 이미 갖고 있는 링크를 **쿠팡파트너스 링크** 입력란에 직접 붙여넣어도 됨
     (이 경우 og:image 스크래핑으로 사진만 보조로 가져옴, API 검색보다 덜 안정적)
2. 본문 작성 + 발행 예정 시각 입력 → 예약 등록
3. 서버가 1분마다 예정 시각이 지난 글을 자동 발행 (`scheduler.js`)
4. **링크가 있는 경우**, 본문 발행 3초 후 자동으로 그 글에 답글(댓글)을 달아
   "쿠팡 파트너스 활동의 일환..." 안내문구 + 링크를 등록합니다 (본문에는 링크가 들어가지 않음)
   - 안내문구 템플릿은 **연결 설정** 탭에서 직접 수정 가능 (`{link}` 자리에 실제 링크 삽입)
   - 글 예약 시 "댓글로 자동 등록" 체크를 해제하면 댓글은 달지 않음
5. 발행 후 10분마다 조회수/좋아요 등 인사이트를 자동 갱신
6. **대시보드** 탭에서 오늘 현황 확인, **전체 글 목록** 탭에서 댓글 등록 성공/실패 여부 확인

## 7. Node.js 버전 요건

DB에 별도 설치 없는 **Node.js 내장 SQLite 모듈**을 사용합니다 (네이티브 빌드 불필요 —
호스팅에서 흔히 겪는 빌드 실패 문제를 피하기 위한 선택). **Node.js 22.5 이상**이 필요합니다.
Railway/Render에서 Node 버전을 지정할 수 있으면 22 이상으로 맞춰주세요.

## 8. 알아두면 좋은 제약

- 스레드 계정당 **하루 250건**까지 발행 가능 (Meta 정책)
- 쿠팡파트너스 상품검색 API는 호출 빈도 제한이 있음 — 검색을 너무 자주 반복하지 말 것
- 링크 직접 붙여넣기로 이미지를 가져오는 스크래핑 방식은 쿠팡이 봇 접근을 차단하거나
  페이지 구조를 바꾸면 실패할 수 있습니다 — 이 경우 이미지 URL을 직접 입력하면 됩니다
  (API 검색을 쓰면 이 문제 자체가 없음)
- 이미지 첨부 시 `image_url`은 외부에서 접근 가능한 공개 URL이어야 함 (직접 업로드 불가, 링크만 가능)
- Threads 장기 액세스 토큰 유효기간은 60일 — 만료 전 갱신 로직은 `threadsApi.js`의
  `refreshLongLivedToken`에 준비되어 있음 (현재는 자동 스케줄 미적용, 필요하면 추가 가능)
- 계정이 바뀌면 (예: 홈템픽 ↔ 젠틀블루) 재연결 절차를 다시 거쳐야 함 — 계정 여러 개 동시 지원은
  아직 미구현 (필요하면 확장 가능)

## 9. AI 글 자동 생성 (선택)

"글 예약" 탭 본문 입력란 위의 **"✨ AI로 글 써주기"** 버튼을 누르면, 광고 느낌 없는
캐주얼한 스레드 본문을 자동으로 써줍니다. 상품 검색으로 고른 상품이나 링크로 가져온
상품 정보를 바탕으로 작성됩니다.

**사용하려면 Anthropic API 키가 필요합니다:**
1. https://console.anthropic.com 가입/로그인
2. API Keys 메뉴에서 새 키 발급 (`sk-ant-...`로 시작)
3. 대시보드 **연결 설정** 탭 → "AI 글 생성" 섹션에 붙여넣고 저장
4. 호출당 소액 과금됩니다 (콘솔에서 사용량/잔액 확인 가능)

이 키가 없어도 나머지 기능(예약 발행, 댓글 자동 등록, 상품 검색)은 정상 작동합니다 —
이 버튼만 못 씁니다.

## 10. 내 사진/영상 직접 첨부 (선택)

검색이나 스크래핑으로 자동으로 채워진 사진이 마음에 안 들면, "글 예약" 탭의
**"📎 내 사진/영상 직접 첨부"** 버튼으로 갖고 계신 사진이나 영상을 올려서 붙일 수 있습니다.
jpg/png/gif/webp 이미지와 mp4/mov 영상을 지원하며, 최대 200MB까지 가능합니다.

- 업로드하면 자동으로 이미지 URL(또는 영상 URL) 칸이 채워지고 미리보기가 뜹니다
- 마음에 안 들면 미리보기 위의 **"✕ 첨부 삭제"**를 눌러 지우고 다시 올릴 수 있습니다
- 영상은 스레드 서버에서 인코딩 처리 시간이 걸려서, 발행 시 최대 1분 정도 대기 후 올라갑니다
- 업로드한 파일은 서버(`uploads` 폴더)에 저장됩니다. Railway 무료 플랜처럼 재배포마다
  파일시스템이 초기화되는 환경에서는 재배포 시 기존 업로드 파일이 사라질 수 있으니,
  중요한 파일은 따로 보관해두는 걸 권장합니다 (영구 디스크/볼륨을 설정하면 유지됩니다)

## 11. 계정 여러 개(최대 5개) 관리

화면 상단에 계정 칩(홈템픽, 젠틀블루 등)이 나란히 뜹니다. 계정마다 스레드 연결,
쿠팡파트너스 키, AI 키, 안내문구 템플릿, 예약된 글이 완전히 독립적으로 저장됩니다.

- **"+ 계정 추가"** 칩을 눌러 이름을 입력하면 새 계정이 생깁니다 (최대 5개)
- 계정 칩을 클릭하면 그 계정으로 전환되고, 대시보드/글 예약/전체 글 목록/연결 설정이
  전부 그 계정 기준으로 바뀝니다
- 연결된 계정은 칩 옆에 초록색 점이 표시됩니다
- **연결 설정 탭 → 계정 관리**에서 현재 선택된 계정의 이름 변경/삭제가 가능합니다
  (삭제하면 그 계정의 예약/발행 기록도 함께 삭제되니 주의)
- 계정마다 Meta 개발자 앱을 따로 만들어서 App ID/Secret/Redirect URI를 등록해야 합니다
  (Redirect URI는 계정이 달라도 같은 배포 주소를 써도 되고, `/auth/callback` 하나로 공용 가능)
